# Brand system — Aurora Glass

Five stylesheets, loaded in this order. The order is the architecture.

```html
<link rel="stylesheet" href="/styles/tokens.css">      <!-- measured palette   -->
<link rel="stylesheet" href="/styles/layout.css">      <!-- geometry only      -->
<link rel="stylesheet" href="/styles/system.css">      <!-- the design language -->
<link rel="stylesheet" href="/styles/components.css">  <!-- per-component       -->
<link rel="stylesheet" href="/styles/chrome.css">      <!-- header/nav/footer    -->
```

---

## Why the first build looked like the original

The first attempt shipped the source's own 184 KB `base.css` as a "structural base"
and layered adjustments on top. That file **is** the original design — it styled every
`.et-*`, `.dc-*`, card, band and grid. Changing type, shadows and motion above it produced
a reskin, not a redesign.

This build removes it. `tools/strip-visuals.mjs` reduces the source CSS to pure geometry:

| | |
|---|---|
| in | 184,426 bytes |
| out | 88,121 bytes (**52% smaller**) |
| dropped | **1,846 visual declarations** — 376 `color`, 219 `font-size`, 178 `background`, 139 `font-family`, 113 `font-weight`, 103 `border-radius`, 84 `box-shadow`, 74 `letter-spacing` … |
| dropped | 74 `@font-face` blocks |
| kept | 1,966 layout declarations — display, grid, flex, gap, size, position, overflow |
| emptied | 253 rules that had nothing left |

Verified after stripping: **0 hex colours, 0 font declarations, 0 shadows, 0 radii** remain.
The only `rgba()` left sits inside `mask-image` gradients, which shape rather than colour.

`layout.css` positions boxes. **It must never be edited to add appearance.**

## 1 · `tokens.css` — the measured palette

Generated by `sr-tokens.mjs` from a live browser capture at five viewports (725–817
elements each, ~90 computed properties per element). 187 tokens.

| token | value | role |
|---|---|---|
| `--c-1` | `#ffffff` | surface white |
| `--c-2` | `#0b7360` | **brand teal** |
| `--c-3` | `#0e1c1e` | deep ink |
| `--c-4` | `#dcefea` | teal tint |
| `--c-5` | `#f7fafb` | paper |
| `--c-6` | `#17262b` | body text |
| `--c-7` | `#edf5f3` | ink on dark |
| `--c-8` | `#4e626a` | muted text |
| `--c-9` | `#edbe72` | gold light |

**The design derives from these.** `system.css` maps its palette onto them
(`--g-teal: var(--c-2)`, `--g-ink: var(--c-3)`, `--g-paper: var(--c-5)` …) and every alpha
value is a `color-mix()` over a token rather than a hardcoded `rgba()`. Change `--c-2` and
the whole site moves. Across the four authored sheets: **43 token references against 20
colour literals**, and 11 of those 20 live in `motion.css`, whose keyframes are verbatim
source and must not be touched.

Two colours are new to this design and have no measured equivalent — `--g-teal-lit`
`#16B393` (the luminous accent) and `--g-gold` `#E0A44C`. Each is declared once.

## 2 · `system.css` — the design language

**The ground.** A fixed aurora sits behind everything: four radial gradients in teal, gold
and mint over paper, blurred 10px, drifting on a 34-second alternating cycle, with an SVG
grain overlay so the gradients never band. Sections are transparent, so it reads through
the entire page and gives the glass something to refract.

**Glass.** `background: color-mix(--c-1 58%)`, `backdrop-filter: blur(22px) saturate(175%)`,
a bright 1px rim, a two-stop ink-tinted shadow, and an inset top highlight. Dark bands get
the inverse: `color-mix(--c-3 58%)` with a light rim.

**Type.** Space Grotesk display at `clamp(36px, 5.1vw, 68px)` with `-0.035em` tracking;
Inter body. Accent words inside headings take a teal→gold gradient fill.

**Motion.** Reveal is blur-in: `opacity 0 → 1`, `translateY(26px) → 0`, `blur(10px) → 0`
over 0.72s with a 90ms sibling stagger.

## 3 · `components.css` — generated, not guessed

`tools/build-components-css.mjs` emits it from two evidence sources:

1. **`audit/redesign-brief.json`** — a 10-agent pass, one per class family, that read the
   built markup and the original CSS and classified 250 components.
2. **`audit/original-cards.json`** — every class the original stylesheet gave a background
   *and* a radius or shadow, i.e. everything that was a surface in the design being replaced.

The union, minus icons, media frames and pills, is the card set. Both sources were needed:
the agent pass missed `.et-svc` (the six home service cards), which rendered with no surface
until the derived list caught it. The brief's own structural warnings are applied as
exclusions — `.dc-pill`, `.dc-visit__row` and `.bw-manifesto__value` are hairline **rows**,
not cards; `.ethc-house` stays bare; `.ha-nap` is not glass.

Current assignment: **27 glass surfaces · 16 media-frame rims · 13 CTA links · 8 pills ·
11 hairline rows · 3 accordions · 9 stats · 10 eyebrows · 51 on-dark selectors.**

Nothing in this file sets `position` or `display`, so `display:contents` re-parenting and
absolutely-positioned inset media keep working.

## 4 · `chrome.css` — the signature

The header starts flush and full width. Past 24px of scroll it **detaches into a floating
glass pill**: max-width clamps to the content column, corners round to a pill, a frosted
background and rim fade in, the bar shrinks from 78px to 64px, the logo from 38px to 32px,
and the dark top bar slides away. All of it on one `is-stuck` class.

## Verification

`audit/redesign-audit.json` — 8 pages × 4 viewports (390/768/1024/1440), each asserting its
own `innerWidth` before measuring: **0 defects.** No horizontal overflow, no collapsed
sections, no unstyled surfaces, no broken images, no text under 3:1.

That audit was wrong four times before it was right, and each correction is recorded in
`tools/audit-page.js`. Most instructive: it reported all 328 glass surfaces as having no
background, because `color-mix()` computes to `color(srgb 1 1 1 / 0.58)` and the parser only
understood `rgba()`. **The tool was broken, not the site** — worth remembering before acting
on any single audit number.

## `motion.css` — harvested, deliberately not shipped

`src/styles/motion.css` holds the 11 source keyframes verbatim (never re-typed — a retyped
keyframe is a different animation). It is **not** linked: all 11 are platform widget
animations (`sg-spinner`, `sgb-progress-stripes` …) for components this build removed.
